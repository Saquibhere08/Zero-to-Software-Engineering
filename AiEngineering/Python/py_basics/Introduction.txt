Python is a high-level, interpreted, general-purpose programming language known for its simple and readable syntax. It supports multiple programming paradigms, 
including procedural, object-oriented, and functional programming.

How python runs code?
* python runs code line by line (interpreter-based)
* no need to compile manually - interpreter handles it
* each line is converted into bytecode , then executed by the Python Virtual Machine(PVM).
* error stops execution immediately

Variable : A varible name can be composed of characters, numbers, the underscore character. It can't start with a number . 
These are all valid variable names.

String: It is a datatype in python, which stores sequence of number,or symbols in ' ' or " " or ''' ''' quotes .
Note:
Strings are immutable, i.e. their contents cannot be changed directly

Slicing: it lets you access a part of a String

upper() - prints the string in uppercase letters
lower() - prints the string in lowercase letters

Conditional Statments: Conditional statements allow a program to make decisions based on whether a condition is True or False.
